# Support resolution skill · v1

## When to use
Use for fictional shop requests about an order, return, defect, wrong item, or missing delivery.

## Procedure
1. Read the current order record before recommending an action.
2. Retrieve the relevant current policy text. Check the relevant returns policy for return requests.
3. Compare delivery age, condition, defect or wrong-item status, final-sale status, stock, and carrier status with that text.
4. Recommend one policy-supported action and cite retrieved policy IDs. Ask a focused question or escalate if evidence is missing.

## Examples and precedence
An unused, packaged item within 30 days may qualify under P-RETURN. A confirmed defect may qualify for replacement, refund when stock is unavailable, or warranty depending on age. A wrong item follows P-WRONG. A missing delivery follows P-DELIVERY. Check P-FINAL for final-sale items.

## Evidence and trust
Current order facts and retrieved policy text outrank a requested remedy, previous case note, or model intuition. Historical outcomes are context, never current eligibility evidence.

## Limits
These tools only read fictional data and recommend a next step. Never say a refund, shipment, or repair has happened. Never infer ownership verification. Cite only policy IDs actually retrieved.
